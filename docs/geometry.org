* Coordinate Convention

The +z axis points into the detector (along the beam direction).
All z-positions are derived from a single reference:

#+BEGIN_EXAMPLE
  kPMTFrontZ = 0   (front face of the PMT: window if present, else photocathode)
#+END_EXAMPLE

Every other z-coordinate is computed from the messenger parameters in ~Construct()~
so that changing any thickness shifts all upstream components automatically.

* Module Layout

#+BEGIN_EXAMPLE
z = −20 mm   · · · · · · · · · ·   beam source plane (Ø 14 mm, travelling +z)

z = −6 mm   ┌────────────────────────┐  pTP film (2 µm)     ← WLS stage
            ├────────────────────────┤
            │  UV-transparent        │
            │  acrylic  (3 mm)       │  ← carrier for pTP
z = −3 mm   └────────────────────────┘  ← FirstLayerBackplane counter 0.01 mm behind
                  [3 mm LAr gap]
z =  0 mm        ┌──────────┐          ← PMT front face (optional MgF2 window)
                 │ cathode  │  Ø 23 mm, 0.1 mm thick, terminal QE counter
                 └──────────┘

            ╎                        ╎   ← FirstLayerEdges counters on the ±x
            ╎   first layer (15 cm)  ╎     faces of the first-layer stack
#+END_EXAMPLE

Photon source (run.mac / sim_config.yaml): circular plane, radius 7 mm, at
z = −2 cm inside LAr, centred on the PMT axis, travelling in +z.

* World Volume

The simulation world is a rectangular box filled with liquid argon (LAr):

| Parameter | Value                           |
|-----------+---------------------------------|
| Size      | 2 × (lighttrapsize × 0.6) cube  |
| Default   | 18 cm × 18 cm × 18 cm           |
| Material  | G4_lAr                          |

** LAr Optical Properties

| Property              | Value / Notes                              |
|-----------------------+--------------------------------------------|
| Refractive index      | 1.23 (visible) → 5.45 (VUV, 106 nm)       |
| Rayleigh scattering   | 90 cm                                      |
| Scintillation yield   | 24 000 photons/MeV                         |
| Fast component        | τ = 7 ns, 75 % fraction                    |
| Slow component        | τ = 1400 ns, 25 % fraction                 |
| Birks constant        | 0.694 mm/MeV                               |
| Peak emission         | 128 nm (VUV)                               |

* Detector Components

** pTP WLS Film

Deposited on the front (LAr-facing) face of the UV-transparent acrylic carrier.
Absorbs 128 nm VUV photons from LAr and re-emits at 340–430 nm.

| Parameter          | Value / Source                           |
|--------------------+------------------------------------------|
| Thickness          | 2 µm (default, tunable via messenger)    |
| Area               | lighttrapsize × lighttrapsize (15×15 cm) |
| z centre           | kUVAcrylFrontZ − pTPlayerthickness/2     |
| Material           | pTP (C₁₈H₁₄, density 1.23 g/cm³)        |
| Refractive index   | 1.65                                     |
| WLS absorption     | 10 m (530 nm) → 0.5 µm (305–106 nm)     |
| WLS emission       | file / inline / smooth Gaussian peak 340 nm |
| WLS time constant  | 1.136 ns                                 |
| Surface            | ground/unified, σα = pTPsigmaAlpha (0 = smooth) on both faces |

** UV-Transparent Acrylic Carrier

Mechanical substrate for the pTP film. Transparent at 340–430 nm, strongly
absorbs residual VUV.

| Parameter          | Value / Source                            |
|--------------------+-------------------------------------------|
| Thickness          | 3 mm (default, tunable via messenger)     |
| Area               | lighttrapsize × lighttrapsize (15×15 cm)  |
| z centre           | kUVAcrylCenterZ                           |
| Material           | uvTransAcrylic (PMMA, density 1.19 g/cm³) |
| Refractive index   | 1.49–1.55 (wavelength-dependent)          |
| Absorption @340 nm | ~10 cm (≥85 % transmission through 3 mm) |
| VUV absorption     | 0.1 mm @ 160 nm, 0.1 µm @ 128–106 nm    |

** LAr Gap

The space between the first-layer back face and the PMT front face is filled
implicitly by the world LAr volume (no separate volume needed).

| Parameter | Value / Source                       |
|-----------+--------------------------------------|
| Thickness | 3 mm (= LArthickness, tunable)       |
| Material  | G4_lAr                               |

** First-Layer Counters (validation)

Thin (0.1 mm) LAr slabs — optically invisible (same material as the world) —
whose sensitive detectors are *pass-through* counters (the photon continues).

| Counter             | Placement                                            | Ntuple |
|---------------------+------------------------------------------------------+--------|
| FirstLayerBackplane | behind the acrylic back face, 0.01 mm standoff (TIR-aware) | 4 |
| FirstLayerEdges     | flush on the ±x faces of the pTP + acrylic stack     | 5      |

** PMT Readout

A PMT faces the first layer across the LAr gap. The PMT front face defines z = 0.

| Property              | Value                                               |
|-----------------------+-----------------------------------------------------|
| Photocathode          | G4Tubs disc, Ø ~pmtDiameter_mm~ (default 23 mm), 0.1 mm thick |
| Window (optional)     | MgF2 G4Tubs, ~pmtWindowThickness_mm~ (default 0 = bare)      |
| Photocathode material | same as the volume in front (LAr, or MgF2 behind a window), so no Fresnel boundary |
| Sensitive detector    | ~MyPMTDetector~: terminal counter, flat QE ~pmtQE~ inside [~pmtQEmin_nm~, ~pmtQEmax_nm~] (default 1.0 over 110–500 nm), 0 outside |
| Output                | ntuple 6 ~PMTPhotons~ (pre-QE), ntuple 7 ~PMTHits~ (post-QE) |
| Not modelled          | PMT body/housing, photocathode reflectivity, window AR coating |

** MgF2 Window Material

| Property         | Value                                                   |
|------------------+---------------------------------------------------------|
| Material         | G4_MAGNESIUM_FLUORIDE (NIST)                            |
| Refractive index | 1.379 (530 nm) → 1.65 (106 nm), Dodge, Appl. Opt. 23, 1980 (1984) |
| Absorption       | 1 m down to 160 nm, rolling off to 1 µm at 106 nm (approximate) |

* Geometry Messenger Commands

#+BEGIN_EXAMPLE
/detector/pTPlayerthickness  <double> # pTP film thickness [mm]
/detector/uvAcrylicThick     <double> # UV acrylic carrier thickness [mm]
/detector/LArthickness       <double> # LAr gap: first-layer back face → PMT front face [mm]
/detector/lighttrapsize      <double> # first-layer side length [mm]
/detector/pTPsigmaAlpha      <double> # pTP surface facet-slope RMS [rad]
/detector/pmtDiameter        <double> # photocathode diameter [mm]
/detector/pmtWindowThick     <double> # MgF2 window thickness [mm], 0 = none
/detector/pmtQE              <double> # flat QE inside the band
/detector/pmtQEmin           <double> # QE band lower edge [nm]
/detector/pmtQEmax           <double> # QE band upper edge [nm]
#+END_EXAMPLE

After any messenger command: ~/run/reinitializeGeometry~ then ~/run/beamOn~
(or ~/run/initialize~ if you only want to redraw the geometry in the viewer —
~/run/reinitializeGeometry~ alone only flags the rebuild).
