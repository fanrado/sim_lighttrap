* Coordinate Convention

The +z axis points into the detector (along the beam direction).
All z-positions are derived from a single reference:

#+BEGIN_EXAMPLE
  kPMTFrontZ = 0   (front face of the PMT faceplate; bare photocathode if the faceplate is disabled)
#+END_EXAMPLE

Every other z-coordinate is computed from the messenger parameters in ~Construct()~
so that changing any thickness shifts all upstream components automatically.

* Module Layout

#+BEGIN_EXAMPLE
z = −20 mm   · · · · · · · · · ·   beam source plane (Ø 14 mm, travelling +z)

z = −10 mm  ┌────────────────────────┐  pTP film (2 µm)     ← WLS stage
            ├────────────────────────┤
            │  UV-transparent        │
            │  acrylic  (3 mm)       │  ← carrier for pTP
z = −7 mm   └────────────────────────┘  ← FirstLayerBackplane counter 0.01 mm behind
                  [7 mm LAr gap]
z =  0 mm        ┌────────────┐        ← MgF2 faceplate, Ø 28.2 mm, 1.5 mm thick
z = 1.5 mm       │ ▒cathode▒  │        ← photocathode Ø 23 mm, 0.1 mm, terminal QE counter
                 │            │
                 │  vacuum    │        ← Hamamatsu R6836 body, opaque glass wall (1 mm)
                 │            │
z = 92 mm        └────────────┘        ← glass end cap

            ╎                        ╎   ← FirstLayerEdges counters on the ±x
            ╎   first layer (15 cm)  ╎     faces of the first-layer stack
#+END_EXAMPLE

Photon source (run.mac / sim_config.yaml): circular plane, radius 7 mm, at
z = −2 cm inside LAr, centred on the PMT axis, travelling in +z.

* World Volume

The simulation world is a rectangular box filled with the selected medium
(~geometry.worldMedium~ / ~/detector/worldMedium~ / CLI ~world_medium=~):

| Parameter | Value                                                        |
|-----------+--------------------------------------------------------------|
| Size      | 2 × (lighttrapsize × 0.6) in x, y; z extended by pmtLength   |
| Default   | 18 cm × 18 cm × (18 + 2·9.2) cm                              |
| Material  | ~gar~ argon gas (G4_Ar, default) · ~lar~ liquid argon · ~vacuum~ |

The gap, the optically invisible counters and a bare photocathode are built
from the same medium; the PMT interior is always vacuum.

** Argon Gas Optical Properties (default)

| Property            | Value / Notes                                                     |
|---------------------+-------------------------------------------------------------------|
| Density             | 1.66 mg/cm³ (NIST G4_Ar, ~1 atm)                                  |
| Refractive index    | 1.000283 (530 nm) → 1.000444 (128 nm), Bideau-Méhu et al. (1981); extrapolated below 140 nm |
| Absorption          | 1000 m (pure Ar transparent above its 106 nm edge; impurities not modelled) |
| Rayleigh scattering | 1000 m (negligible at 1 atm)                                      |

** LAr Optical Properties (worldMedium: lar)

| Property              | Value / Notes                              |
|-----------------------+--------------------------------------------|
| Refractive index      | 1.23 (visible) → 5.45 (VUV, 106 nm)       |
| Rayleigh scattering   | 90 cm                                      |
| Scintillation yield   | 24 000 photons/MeV                         |
| Fast component        | τ = 7 ns, 75 % fraction                    |
| Slow component        | τ = 1400 ns, 25 % fraction                 |
| Birks constant        | 0.694 mm/MeV                               |
| Peak emission         | 128 nm (VUV)                               |

* Detector Components

** pTP WLS Film

Deposited on the front (LAr-facing) face of the UV-transparent acrylic carrier.
Absorbs 128 nm VUV photons from LAr and re-emits at 340–430 nm.

| Parameter          | Value / Source                           |
|--------------------+------------------------------------------|
| Thickness          | 2 µm (default, tunable via messenger)    |
| Area               | lighttrapsize × lighttrapsize (15×15 cm) |
| z centre           | kUVAcrylFrontZ − pTPlayerthickness/2     |
| Material           | pTP (C₁₈H₁₄, density 1.23 g/cm³)        |
| Refractive index   | 1.65                                     |
| WLS absorption     | 10 m (530 nm) → 0.5 µm (305–106 nm)     |
| WLS emission       | file / inline / smooth Gaussian peak 340 nm |
| WLS time constant  | 1.136 ns                                 |
| Surface            | ground/unified, σα = pTPsigmaAlpha (0 = smooth) on both faces |

** UV-Transparent Acrylic Carrier

Mechanical substrate for the pTP film. Transparent at 340–430 nm, strongly
absorbs residual VUV.

| Parameter          | Value / Source                            |
|--------------------+-------------------------------------------|
| Thickness          | 3 mm (default, tunable via messenger)     |
| Area               | lighttrapsize × lighttrapsize (15×15 cm)  |
| z centre           | kUVAcrylCenterZ                           |
| Material           | uvTransAcrylic (PMMA, density 1.19 g/cm³) |
| Refractive index   | 1.49–1.55 (wavelength-dependent)          |
| Absorption @340 nm | ~10 cm (≥85 % transmission through 3 mm) |
| VUV absorption     | 0.1 mm @ 160 nm, 0.1 µm @ 128–106 nm    |

** Gap

The space between the first-layer back face and the PMT faceplate is filled
implicitly by the world volume (no separate volume needed).

| Parameter | Value / Source                              |
|-----------+---------------------------------------------|
| Thickness | 7 mm (= LArthickness, tunable)              |
| Material  | world medium (argon gas by default)         |

** First-Layer Counters (validation)

Thin (0.1 mm) LAr slabs — optically invisible (same material as the world) —
whose sensitive detectors are *pass-through* counters (the photon continues).

| Counter             | Placement                                            | Ntuple |
|---------------------+------------------------------------------------------+--------|
| FirstLayerBackplane | behind the acrylic back face, 0.01 mm standoff (TIR-aware) | 4 |
| FirstLayerEdges     | flush on the ±x faces of the pTP + acrylic stack     | 5      |

** PMT Readout (Hamamatsu R6836)

A PMT faces the first layer across the 7 mm LAr gap; its faceplate front
defines z = 0. Dimensions follow the R6836 datasheet (TPMH1264E): tube and
faceplate Ø 28.2 ± 0.8 mm, photocathode Ø 23 mm min. effective area, body
92 ± 2 mm, MgF2 window, Cs-Te photocathode (115–320 nm).

| Property              | Value                                               |
|-----------------------+-----------------------------------------------------|
| Faceplate             | MgF2 G4Tubs, Ø ~pmtTubeDiameter_mm~ (28.2 mm), ~pmtWindowThickness_mm~ thick (1.5 mm — not on the datasheet, assumption; 0 = bare photocathode) |
| Photocathode          | G4Tubs disc, Ø ~pmtDiameter_mm~ (23 mm), 0.1 mm thick, on the inner faceplate surface (daughter of the vacuum) |
| Photocathode material | same as the faceplate (MgF2; LAr if the faceplate is disabled), so no Fresnel boundary at its face |
| Vacuum interior       | G4_Galactic with RINDEX = 1, r < R_tube − wall, from the faceplate to the end cap |
| Envelope / end cap    | G4_Pyrex_Glass without optical properties → perfectly absorbing; wall ~pmtWallThickness_mm~ (1 mm); length ~pmtLength_mm~ (92 mm) |
| Sensitive detector    | ~MyPMTDetector~: terminal counter, flat QE ~pmtQE~ inside [~pmtQEmin_nm~, ~pmtQEmax_nm~] (default 1.0 over 110–500 nm), 0 outside — or the interpolated table from ~pmtQEFile~ |
| Output                | ntuple 6 ~PMTPhotons~ (pre-QE), ntuple 7 ~PMTHits~ (post-QE) |
| Not modelled          | dynodes, pins, photocathode reflectivity, faceplate AR coating, real Cs-Te QE curve |

** MgF2 Faceplate Material

| Property         | Value                                                   |
|------------------+---------------------------------------------------------|
| Material         | G4_MAGNESIUM_FLUORIDE (NIST)                            |
| Refractive index | 1.379 (530 nm) → 1.65 (106 nm), Dodge, Appl. Opt. 23, 1980 (1984) |
| Absorption       | 1 m down to 160 nm, rolling off to 1 µm at 106 nm (approximate) |

* Geometry Messenger Commands

#+BEGIN_EXAMPLE
/detector/worldMedium        <string> # gar (argon gas, default) | lar | vacuum
/detector/withSample         <bool>   # build the pTP-coated acrylic sample (false = bare beam → PMT reference)
/detector/pTPlayerthickness  <double> # pTP film thickness [mm]
/detector/uvAcrylicThick     <double> # UV acrylic carrier thickness [mm]
/detector/LArthickness       <double> # LAr gap: back of the acrylic → PMT faceplate [mm] (7)
/detector/lighttrapsize      <double> # first-layer side length [mm]
/detector/pTPsigmaAlpha      <double> # pTP surface facet-slope RMS [rad]
/detector/pmtDiameter        <double> # photocathode diameter [mm] (23)
/detector/pmtTubeDiameter    <double> # tube / faceplate diameter [mm] (28.2)
/detector/pmtLength          <double> # faceplate front → end of glass body [mm] (92)
/detector/pmtWindowThick     <double> # MgF2 faceplate thickness [mm] (1.5), 0 = none
/detector/pmtWallThick       <double> # envelope wall / end-cap thickness [mm] (1)
/detector/pmtQE              <double> # flat QE inside the band
/detector/pmtQEmin           <double> # QE band lower edge [nm]
/detector/pmtQEmax           <double> # QE band upper edge [nm]
/detector/pmtQEFile          <string> # "<wl_nm> <QE>" table replacing the flat band (empty = flat)
/detector/worldHalfZ         <double> # world half-length in z [mm], 0 = automatic
#+END_EXAMPLE

After any messenger command: ~/run/reinitializeGeometry~ then ~/run/beamOn~
(or ~/run/initialize~ if you only want to redraw the geometry in the viewer —
~/run/reinitializeGeometry~ alone only flags the rebuild).
