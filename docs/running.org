* Prerequisites

- Geant4 ≥ 11.x compiled with UI drivers and visualisation (Qt / TOOLSSG);
  this laptop uses Geant4 11.3.2 from spack.
- CMake ≥ 3.5, a C++17 compiler.
- yaml-cpp (found via CMake, or fetched automatically).
- ROOT (for output file analysis; not a compile-time dependency),
  Python 3 with uproot + matplotlib for ~analysis/plot_pmt_validation.py~.

Point CMake at Geant4 either by sourcing ~geant4.sh~ or via
~GEANT4_CMAKE_DIR~ / ~-DGeant4_DIR~.

* Building

#+BEGIN_SRC bash
cd sim_lighttrap
mkdir build && cd build
cmake ..          # add -DCMAKE_C_COMPILER=/usr/bin/cc -DCMAKE_CXX_COMPILER=/usr/bin/c++ on macOS with miniconda on PATH
make -j8
#+END_SRC

The executable ~sim_lighttrap~, all macros, input data and ~sim_config.yaml~ are
placed in the build directory by CMake (~file(COPY ...)~ directives).

* Running

** Interactive mode (visualisation)

#+BEGIN_SRC bash
./sim_lighttrap
#+END_SRC

Loads ~vis.mac~ automatically: Qt viewer with the first layer and the PMT
photocathode, axes and scale, trajectories accumulated per event, and the
14 mm VUV beam preloaded (Run menu → beamOn 30).

** Batch mode (standard run)

#+BEGIN_SRC bash
./sim_lighttrap run.mac
#+END_SRC

Runs 10 000 events with the default beam (circular plane, radius 7 mm, at
z = −2 cm, λ = 128 nm, along +z). Output: ~output_apexltsim0.root~.

** World medium

#+BEGIN_SRC bash
./sim_lighttrap sim_config.yaml world_medium=gar     # argon gas (default)
./sim_lighttrap sim_config.yaml world_medium=lar     # liquid argon
#+END_SRC

** With / without the sample

#+BEGIN_SRC bash
./sim_lighttrap sim_config.yaml with_sample=on    # sample in the beam (default)
./sim_lighttrap sim_config.yaml with_sample=off   # bare beam → PMT reference, identical geometry
#+END_SRC

~with_sample=off~ removes the pTP film, the UV acrylic and the first-layer edge
counters; beam, gap, PMT and the ~FirstLayerBackplane~ reference-counter plane
stay in place. Also ~geometry.withSample~ in the YAML and
~/detector/withSample true|false~ in a macro.

** YAML configuration

#+BEGIN_SRC bash
./sim_lighttrap sim_config.yaml           # geometry + source + nEvents from YAML
./sim_lighttrap sim_config.yaml run.mac   # YAML geometry, macro source/run
#+END_SRC

** Headless geometry pictures

#+BEGIN_SRC bash
./sim_lighttrap draw_offscreen.mac        # writes pmt_geom_*.png, prints the volume tree
#+END_SRC

* Runtime Geometry Configuration

Inside an interactive session or at the top of a custom macro:

#+BEGIN_EXAMPLE
/detector/LArthickness 10
/detector/pmtWindowThick 2
/run/reinitializeGeometry
/run/beamOn 10000
#+END_EXAMPLE

| Command                   | Default | Effect                                        |
|---------------------------+---------+-----------------------------------------------|
| /detector/worldMedium     | gar     | argon gas (default) · lar · vacuum            |
| /detector/withSample      | true    | build the pTP-coated acrylic sample (false = reference) |
| /detector/pTPlayerthickness | 0.002 mm | pTP film thickness                          |
| /detector/uvAcrylicThick  | 3 mm    | UV acrylic carrier thickness                  |
| /detector/LArthickness    | 7 mm    | LAr gap, back of the acrylic → PMT faceplate  |
| /detector/lighttrapsize   | 150 mm  | first-layer side length                       |
| /detector/pTPsigmaAlpha   | 0 rad   | pTP surface roughness                         |
| /detector/pmtDiameter     | 23 mm   | photocathode diameter                         |
| /detector/pmtTubeDiameter | 28.2 mm | tube / faceplate diameter                     |
| /detector/pmtLength       | 92 mm   | faceplate front → end of glass body           |
| /detector/pmtWindowThick  | 1.5 mm  | MgF2 faceplate thickness (0 = none)           |
| /detector/pmtWallThick    | 1 mm    | envelope wall / end-cap thickness             |
| /detector/pmtQE           | 1.0     | flat QE inside the band                       |
| /detector/pmtQEmin        | 110 nm  | QE band lower edge                            |
| /detector/pmtQEmax        | 500 nm  | QE band upper edge                            |

* Output

ROOT file is written to the working directory:

#+BEGIN_EXAMPLE
output_apexltsim<runID>.root
#+END_EXAMPLE

Open with ROOT:

#+BEGIN_SRC cpp
TFile *f = TFile::Open("output_apexltsim0.root");
f->ls();                                   // list all TTrees
TTree *hits = (TTree*)f->Get("PMTHits");
hits->Draw("fX:fY","","colz");             // 2D photocathode hit map
#+END_SRC

See [[file:analysis.org][Output Ntuples & Analysis]] for the full branch reference.

* Macro Files Reference

| File                     | Purpose                                                        |
|--------------------------+----------------------------------------------------------------|
| mac/vis.mac              | Interactive visualisation; loaded automatically with no args   |

** Wavelength scan (transmission spectrum)

#+BEGIN_SRC bash
python3.13 scripts/scan_wavelength.py --build build --events 5000 --range 110 320 10
#+END_SRC

Runs one simulation per wavelength in its own scratch directory and prints
photocathode hits per beam photon, split into unshifted and pTP-shifted light.

* Tips

- Increase verbosity for debugging: ~/tracking/verbose 2~ or ~/event/verbose 1~.
- To suppress visualisation overhead in large runs, always use batch mode.
- The output file name is fixed; run verification jobs in a scratch directory
  so you do not overwrite a long production run.
- Physics random seed can be set with ~/random/setSeeds <s1> <s2>~ for
  reproducible results.
