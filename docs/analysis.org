* Output File

The simulation writes a ROOT file named:

#+BEGIN_EXAMPLE
output_apexltsim<runID>.root
#+END_EXAMPLE

The file contains 8 TTrees (ntuples). They are created in ~src/run.cc~
(~MyRunAction~ constructor) and filled by the tracking, event and sensitive
detector actions. Positions are in mm, times in ns, wavelengths in nm.

* Ntuple Reference

** Ntuple 0 — Energy

Total energy deposited per event across all volumes (0 for optical runs).

| Branch | Type   | Description               |
|--------+--------+---------------------------|
| fEdep  | double | Total energy deposit (MeV)|

** Ntuple 1 — Primary

Properties of the primary (beam) photon at the start of each event.

| Branch           | Type   | Description                          |
|------------------+--------+--------------------------------------|
| eventID          | int    | Geant4 event number                  |
| posX, posY, posZ | double | Primary vertex position (mm)         |
| momX, momY, momZ | double | Momentum (eV)                        |
| wl               | double | Photon wavelength (nm)               |
| pdg              | int    | PDG code (−22 for optical photon)    |

** Ntuple 2 — WLSPhoton

Secondary photons produced by WLS absorption (pTP) or scintillation (LAr).

| Branch           | Type   | Description                                        |
|------------------+--------+----------------------------------------------------|
| eventID          | int    | Geant4 event number                                |
| posX, posY, posZ | double | Emission position (mm)                             |
| cosTheta         | double | Zenith angle cosine of emission direction          |
| phi              | double | Azimuthal angle of emission direction (rad)        |
| processName      | int    | Creator process: 100=Scintillation, 101=OpWLS      |
| t                | double | Global emission time (ns)                          |
| pdg              | int    | PDG code                                           |
| wl               | double | Emitted wavelength (nm)                            |
| matName          | int    | Emission material (NameMap): 1=pTP, 4=LAr, 5=uvTransAcrylic |

** Ntuple 3 — OpticalValidation

Records primary photon trajectories for Fresnel reflection validation.

| Branch           | Type   | Description                                      |
|------------------+--------+--------------------------------------------------|
| eventID          | int    | Geant4 event number                              |
| wavelength       | double | Photon wavelength (nm)                           |
| incidentAngle    | double | Angle of incidence relative to z-axis (deg)      |
| material         | string | Material in which the primary started            |
| reflected        | int    | 1 if the photon ended at z < its vertex z        |
| posX, posY, posZ | double | Initial position (mm)                            |

** Ntuple 4 — FirstLayerBackplane

Photons crossing the back (+z) face of the first layer into the LAr gap
(pass-through counter, 0.01 mm behind the acrylic so TIR-trapped light is
not counted).

| Branch           | Type   | Description                                        |
|------------------+--------+----------------------------------------------------|
| eventID          | int    | Geant4 event number                                |
| fX, fY, fZ       | double | Crossing position (mm)                             |
| fT               | double | Global time (ns)                                   |
| fwl              | double | Photon wavelength (nm)                             |
| fcosTheta        | double | Momentum-z direction cosine                        |
| forward          | int    | 1 if travelling +z (toward the PMT), else 0        |

** Ntuple 5 — FirstLayerEdges

Photons reaching the ±x edges of the first-layer stack. Same columns as
ntuple 4.

** Ntuple 6 — PMTPhotons

Every photon reaching the PMT photocathode, before the quantum efficiency.

| Branch           | Type   | Description                                        |
|------------------+--------+----------------------------------------------------|
| eventID          | int    | Geant4 event number                                |
| fX, fY, fZ       | double | Entry position on the photocathode (mm)            |
| fT               | double | Global arrival time (ns)                           |
| fwl              | double | Photon wavelength (nm)                             |
| fcosTheta        | double | Momentum-z cosine at entry (+1 = normal incidence) |
| primary          | int    | 1 = unshifted beam photon, 0 = pTP WLS daughter    |

** Ntuple 7 — PMTHits

Detected photo-electrons (subset of ntuple 6 passing the QE roll). Same
columns as ntuple 6.

* Key Analysis Quantities

| Quantity                        | Ntuples | How to compute                                        |
|---------------------------------+---------+-------------------------------------------------------|
| pTP WLS efficiency              | 2 / 1   | N(WLSPhoton, matName=1) / N(Primary)                  |
| First-layer escape (back face)  | 4 / 2   | N(FirstLayerBackplane, forward=1) / N(WLS in pTP)     |
| First-layer edge loss           | 5 / 2   | N(FirstLayerEdges) / N(WLS in pTP)                    |
| Geometric collection on the PMT | 6 / 4   | N(PMTPhotons) / N(FirstLayerBackplane, forward=1)     |
| PMT detection efficiency        | 7 / 6   | N(PMTHits) / N(PMTPhotons)                            |
| Photo-electrons per primary     | 7 / 1   | N(PMTHits) / N(Primary)                               |
| Direct VUV on the PMT           | 6       | N(PMTPhotons, primary=1)                              |
| Fresnel reflection vs angle     | 3       | ~reflected~ rate binned in ~incidentAngle~            |
| WLS emission angular dist.      | 2       | Distribution of ~cosTheta~ and ~phi~                  |
| Photocathode hit map            | 6 / 7   | 2D histogram of (fX, fY)                              |

~analysis/analyze_efficiency.py~ prints this chain; ~analysis/Analyze_out.C~
produces a per-tree summary PDF; ~analysis/plot_pmt_validation.py~ makes the
beam-footprint / hit-map / z-stack validation figure; ~scripts/scan_wavelength.py~
repeats the run over beam wavelengths for the transmission spectrum.

* Input Data

** ptp_emission.dat

Wavelength (nm) vs. relative intensity of the pTP emission spectrum; used when
~materials.ptp.wlscomponent_file~ is set in ~sim_config.yaml~.

** spectrum.txt (1905 lines)

Wavelength (nm) vs. relative intensity of the measured lamp spectrum
(~190–900 nm). ~input/create_macro.py~ converts it into the GPS ~Arb~
histogram ~mac/spectrum_macro.mac~ used by ~run_285.mac~.
